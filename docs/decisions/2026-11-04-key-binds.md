# Key binds

- Status: accepted
- Date: 2026-11-04

## Context

Every key was written into the code where it was heard (`Key.E` in the hero, `Key.B` in the build menu, about ten
files) and into the text that names it ("[E] Open door", "Handbook (J)"). A player could not move an action to another
key, which some players need.

## Decision

- **A `Controls` page**, in the title and in the Esc menu beside Settings: a row per action, its key on a button. A
  click on the button waits for a key ("press a key…"); Esc while waiting changes nothing. Reset all puts the defaults
  back. Applied at once, kept on this machine in `user://settings.cfg` (`[binds]`, an action's id and Godot's name of the
  key, only those changed). A dev run plays on the defaults and keeps nothing, so its scripts press the keys they know.
- **One key per action, 22 actions**: walk left, right, up, down, jump, sprint (the jetpack too), use, breathe, suit mode,
  inventory, drop (and pick, while building: one action, so no key is shared), build, search, the three plan modes,
  tablet, black market, Handbook, air overlay, zoom in, zoom out. The arrows walk and the keypad's + and − zoom always,
  beside whatever is bound.
- **Fixed, never bound**: Esc, the dev panel's backquote, the hotbar's 1–0, Enter, Ctrl, Alt, the system key, the arrows
  and the keypad's + and −. Pressing one while waiting is refused, saying why. The mouse is not bound.
- **A key another action has is swapped**: that action takes this one's old key, and the page says with which. So every
  action always has a key, and no key does two things.
- **Keys by their place** (physical keys), as before: a Russian layout plays the same. A key is shown by the letter the
  current layout puts there when that is Latin (an AZERTY player sees Z where QWERTY has W), else by the QWERTY name;
  named keys (Space, Shift, Tab) by their i18n `key.<name>`.
- **Text names keys by placeholders**: `{key:use}` in an En or Ru string is the key bound to Use, filled by `T` itself,
  so no caller changes. A label set once (`Retold`) is told again after a rebind as after a change of language.
- `game/shared/logic/Binds.cs` (Godot-free) holds the actions, defaults, reserved keys, the swap and the saved form;
  `game/shared/BindKeys.cs` is the only place that turns an action into a Godot key.

## Not handled

- Mouse buttons, chords (Ctrl+E), gamepads, two keys for one action, binds kept per world.
- A settings file edited by hand to give two actions one key: both fire.
- A layout switched mid-run: a label set once keeps the old letter until the next rebind or change of language.
